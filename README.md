# William Marshall — Project Delivery

Static site. No build step. Host it on GitHub Pages.

## Publish

1. Create a new public repository. Do not put this inside the finance site repo unless you want both sites fighting over the root.
2. Upload every file in this folder to the repository root: `index.html`, `work.html`, `record.html`, `site.css`, `.nojekyll`.
3. Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
4. The site will be at `https://<user>.github.io/<repo>/`.

Links are relative, so a project site (`username.github.io/repo/`) and a user site (`username.github.io`) both work. If this becomes the user site, it replaces whatever is currently at the root of `username.github.io`. Keep the finance site in its own repo if you still want it live.

## Before you send the URL to anyone

- Confirm Blue Genie dates. This copy says 2015–2021.
- Name the bank if you can say it in public.
- Add a phone number in the footer of all three pages if you want field people to reach you before email.
